我的项目

以下是我在 GitHub 上开源的一些项目，涵盖了后端开发、分布式系统、物联网等多个领域。

🔧 分布式任务调度平台

distributed-scheduler

基于 Go + Gin + etcd + MySQL + Redis 的分布式任务调度平台，支持 Cron 调度、服务发现、分片广播等特性。

  • 技术栈: Go, Gin, etcd, MySQL, Redis
  • 核心特性: Cron表达式调度、7种路由策略（含分片广播）、服务注册与发现、任务分片、失败重试、任务依赖
  • 适用场景: 大规模分布式任务调度、定时任务管理

🚨 物联网设备监控告警系统

iot-alert-system

基于 FastAPI + MySQL + Redis 的物联网设备监控告警系统，支持实时告警、规则引擎、WebSocket 推送。

  • 技术栈: Python, FastAPI, MySQL, Redis, WebSocket
  • 核心特性: JWT认证、告警规则引擎、告警冷却机制、多渠道通知、实时监控大屏
  • 适用场景: IoT设备监控、工业设备告警、环境监测

📊 IoT 数据洞察平台

data-insight-platform

IoT 数据洞察平台 - Go + Gin + Vue3 + ECharts，零 CGO 设计，求职定制 Demo。

  • 技术栈: Go, Gin, SQLite, Vue3, ECharts
  • 核心特性: 零CGO设计、数据可视化、实时图表、设备管理
  • 适用场景: IoT数据展示、设备监控面板

⏰ 分布式任务调度平台 (Java)

task-scheduler-platform

基于 Spring Boot 3.2.5 + MyBatis-Plus + Redisson 的分布式任务调度平台。

  • 技术栈: Java, Spring Boot, MyBatis-Plus, Redisson
  • 核心特性: 动态任务调度、JWT黑名单、任务分片、失败重试
  • 适用场景: 企业级任务调度、定时任务管理

🏭 工业仓库环境监测系统

industrial-warehouse-monitoring

基于 STM32F103 + ESP8266 + 华为云 IoT 的工业仓库环境监测系统（温湿度/光照/TDS水质），含 Keil 工程源码与毕设文档。

  • 技术栈: C, STM32F103, ESP8266, 华为云 IoT
  • 核心特性: 多传感器数据采集、MQTT协议、云端数据存储、实时告警
  • 适用场景: 工业环境监测、仓库温湿度监控、水质监测

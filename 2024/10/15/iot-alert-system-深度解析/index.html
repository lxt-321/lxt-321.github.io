【项目解析】iot-alert-system — 基于 FastAPI 的物联网设备监控告警系统

项目概述

iot-alert-system 是一个完整的物联网设备监控告警系统，支持设备注册、心跳检测、实时告警推送和管理后台。项目采用 FastAPI + MySQL + Redis + WebSocket 技术栈，实现了从设备接入到告警处理的全链路功能。

GitHub：lxt-321/iot-alert-system

技术栈：Python 3.11 · FastAPI · SQLAlchemy 2.0 · MySQL 8.0 · WebSocket · JWT · Redis · Docker

面试可聊点

  1. JWT vs Session：为什么选择 JWT 做设备鉴权？Token 过期如何处理？
  2. WebSocket 维护：连接断开如何感知？心跳机制如何设计？
  3. Redis 冷却去重：如何用 SETNX 实现分布式环境下的告警去重？
  4. 告警状态机：pending → acknowledged → resolved 的状态流转如何实现？
  5. 数据库选型：为什么 MySQL 而非 MongoDB？

【项目解析】distributed-scheduler — 用 Go 实现分布式任务调度平台（XXL-Job 风格）

项目概述

distributed-scheduler 是一个仿 XXL-Job 的分布式任务调度平台，使用 Go + Gin + etcd + MySQL + Redis 实现。包含调度中心、执行器管理、7 种路由策略、分布式锁、失败重试等核心功能。

GitHub：lxt-321/distributed-scheduler

技术栈：Go 1.22 · Gin · etcd · MySQL 8.0 · Redis

项目亮点

维度 内容
代码规模 24 个源文件，1700+ 行代码
路由策略 7 种策略（轮询/随机/一致性哈希/最小连接/故障转移/忙碌转移/分片广播）
服务发现 etcd Lease 实现执行器自动注册与故障剔除
分布式锁 Redis SETNX + Lua 脚本，防止任务重复触发
可靠性 失败重试 + 指数退避 + 超时控制
架构 XXL-Job 风格，易理解易扩展

面试可聊点

  1. etcd vs ZooKeeper：为什么选 etcd？Lease 机制如何理解？
  2. 分布式锁的实现：SETNX + 过期时间有什么坑？（锁续期/锁误删问题）
  3. 一致性哈希：虚拟节点如何解决数据倾斜？
  4. 分片广播：如何保证所有分片执行成功？部分失败如何处理？
  5. 多调度中心：调度中心挂了怎么办？（etcd 选举 or 简单竞争）
  6. Cron 解析：6 位 Cron vs 5 位 Cron 的区别？
